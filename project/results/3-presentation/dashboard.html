Dashboard Yield, Rework & Defect

Lini perakitan smartphone, 10 stasiun, 3 model, 2 shift. Data simulasi buatan sendiri: angka membuktikan metode, bukan kondisi pabrik sebenarnya.

Rumus: FPY = OK percobaan pertama ÷ input. RTY = hasil kali FPY semua stasiun terpilih. Final yield = hasil kali (OK pertama + OK rework) ÷ input. Rework rate = unit NG ÷ input stasiun pertama terpilih. Scrap rate = scrap ÷ input stasiun pertama terpilih. Recovery = rework OK ÷ (OK + scrap). rework_log tidak punya kolom shift, jadi saat filter Shift aktif, Final yield dan Scrap rate tidak dihitung ("-") dan bagian Rework tetap memakai semua shift. Semua KPI dihitung ulang di browser dari tabel harian.
